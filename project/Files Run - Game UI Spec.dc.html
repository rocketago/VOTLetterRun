Subway-runner endless chase. The runner heads up the tunnel toward the vanishing point carrying a stack of pages; the pursuer fills the bottom of the frame, nearest the camera. Two HUD directions over the same screens: 1a keeps chrome on the frame edges, 1b puts a full arcade dashboard along the bottom. 1a covers all seven screens; 1b covers the three where HUD density actually changes. Every dashed box is a sprite placeholder — final art is pixel art, listed in the asset table at the bottom.
1a
Minimal chrome
HUD sits on the frame edges so the tunnel is never occluded. Proximity is a hairline that fills across the top and bleeds red as the pursuer closes. Cleanest read; least legible for a first-time player.

1b
Arcade dashboard
A fixed 190 px dashboard takes the bottom of the frame: pages as discrete tiles, proximity as a segmented gauge, the power-up as a slot that fills on pickup. More legible cold, and drop or gas events have somewhere to animate. The trade-off is real with the flipped camera — the pursuer now sits above the dashboard rim rather than at the screen edge, so the chase reads with less depth. Only the screens where HUD density changes are shown.
